# My Internship Projects

This repository contains three completed projects
developed during my internship.

## Projects

### 1. SEO Sitemap and Robots.txt Configuration

**Description:**
A website SEO configuration project that uses
sitemap.xml and robots.txt to help search engines
understand website structure.

**Technologies:**
- HTML
- CSS
- JavaScript
- XML

**How to Run:**
1. Open the project folder.
2. Open index.html in a web browser.

### 2. Inventory Management System

**Description:**
A C++ application used to manage inventory items
and maintain inventory records.

**Technologies:**
- C++
- File Handling

**How to Run:**
1. Open the project in VS Code.
2. Compile main.cpp.
3. Run the generated executable.

### 3. Maze Solver

**Description:**
A C++ console application that solves a maze
using the recursive backtracking algorithm.

**Technologies:**
- C++
- Recursion
- Backtracking

**How to Run:**
1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile using:

   g++ main.cpp maze.cpp -o MazeSolver

4. Run using:

   .\MazeSolver.exe
